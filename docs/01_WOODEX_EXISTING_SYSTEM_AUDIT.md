## Scope and evidence boundaries

The repository has 371 files under `src`, 44 under `supabase` and 31 under `e2e` at this snapshot. We enumerated the tree, reviewed the architecture, route registry, adapter seams, migrations and selected high-risk flows, and cross-referenced the earlier local audit and Phase 1 test reports. We triaged 265 requested feature rows in `02_WOODEX_FEATURE_COMPLETION_MATRIX.md`. **We have not line-by-line audited every source file or tested every CRUD, responsive/error/empty state or provider.** Treat unreviewed behavior as unverified, not working. The attached `writing-block.md` was previously read in full; the originally requested master-prompt path was absent.

Hosted Supabase/Auth/Storage/Edge revisions, real Bagisto, Vercel configuration, website and real customer records were not accessed. Outbound access to the live site/backend is not available in this environment. No hosted migration, production test, record change, commit, push or deployment was performed. Synthetic browser tests intercept external requests. PGlite and mocked Auth are not actual hosted Postgres/Supabase, real provider, real concurrency, money movement or production-security proof.

## Verified, partial and unknown

- **Locally exercised:** selected PGlite role boundaries, quote acceptance gate, restoration, procurement/settings reads, snapshot boundaries; demo smoke and mocked/isolated browser tests described in 07. These do not establish complete modules.
- **Partial/code present:** all major business areas have at least some UI/model/code. UI-only examples include preview-only builder forms; Bagisto many explicit 501 endpoints and Supabase hosted chat unsupported.
- **Broken or risky:** previously reproduced analytics date-label defect and historical draft/restore/anonymous-order security defects (locally mitigated); the builder ProductRail route mismatch reproduced and repaired locally. Current dashboard sample is only a bounded local mitigation, not complete financial reporting.
- **Missing/not established:** buyer account, transactional full journey, real payment settlement, independent customer approvals, full finance, server-enforced QC, safe hosted AI/chat, complete website builder rollout, comprehensive monitoring/backups.
- **Unknown:** live deployment revision, schema/RLS, actual customer data, external provider access and real-world performance. No honest global business-completion percentage can be calculated until all feature acceptance criteria and actual data-source tests are defined and executed.
